### Step 3 — Implement Theme Toggle JavaScript logic
- **Goal:** Write vanilla JavaScript to toggle the `data-theme` attribute on the `<html>` element when the theme button is clicked.
- **Source:** Agenda 2 mini-report (authoritative)
- **Files:** `script.js`
- **Instructions:**
  1. Create `script.js` in the workspace root.
  2. Select the toggle button using `document.getElementById('theme-toggle')`.
  3. Add a `click` event listener to the button.
  4. Inside the listener, check if `document.documentElement.getAttribute('data-theme')` is `'light'`.
  5. If it is `'light'`, set it to `'dark'` (or remove the attribute to fall back to `:root` defaults). If not, set it to `'light'`.
  6. Do not use any external libraries or frameworks.
  7. Do not include any `console.log` statements.
- **Official Data (verbatim):** not discussed
- **Sample Code (reference only):**
```javascript
const toggle = document.getElementById('theme-toggle');
toggle.addEventListener('click', () => {
  const current = document.documentElement.getAttribute('data-theme');
  if (current === 'light') {
    document.documentElement.removeAttribute('data-theme');
  } else {
    document.documentElement.setAttribute('data-theme', 'light');
  }
});
```
