# CU Adaptive Brain — mabadiliko tu

Kifurushi hiki kina **files zilizobadilishwa/kuongezwa tu**, si ZIP ya project nzima.

1. Soma `docs/CU-ADAPTIVE-BRAIN-IMPLEMENTATION.md` kwanza.
2. Hakiki commit na tengeneza branch/backup kwenye repo halisi.
3. Nakili files kwa paths zake zinazolingana au tumia patch iliyotolewa.
4. Groq imeondolewa kwenye CU tu; usifute config za Groq zinazotumiwa na Board.
5. Fanya tests za local kisha staged real tests za Koyeb kulingana na mwongozo. Hakuna live Koyeb/provider test iliyofanywa wakati wa kuandaa files hizi.
